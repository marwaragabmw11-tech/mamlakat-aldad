# 🐉 مملكة الضاد

**موسوعة تفاعلية لتعليم اللغة العربية للأطفال من 8 إلى 14 سنة**، يرافقهم فيها التنين «ضادون» عبر ثمانية مستويات، من الحروف إلى الخطابة والنقد الأدبي.

موقع ثابت بلا خادم وبلا اشتراكات مدفوعة، ويعمل على الحاسوب والجوال. يُرفع كما هو على GitHub Pages، وكل تقدم الطفل يُحفظ في متصفحه فقط.

## التشغيل على جهازك

لأن الموقع يحمّل ملفات المحتوى، شغّله من خادم محلي بسيط بدل فتح الملف مباشرة:

```bash
# داخل مجلد المشروع
python3 -m http.server 8000
# ثم افتح: http://localhost:8000
```

---

## الرفع على GitHub Pages

1. أنشئ مستودعًا جديدًا على GitHub (مثلًا `mamlakat-aldad`).
2. ارفع **كل محتويات المجلد** كما هي، ومنها ملف `.nojekyll` (ضروري لأن بعض الملفات تبدأ بشرطة سفلية `_`).
3. افتح: **Settings ← Pages ← Source: Deploy from a branch ← Branch: `main` / `(root)`** ثم اضغط **Save**.
4. بعد دقيقة أو اثنتين يظهر الرابط: `https://اسم-المستخدم.github.io/mamlakat-aldad/`

## إضافة محتوى جديد (بلا برمجة)

كل نوع له ملف وصيغة بسيطة. بعد إنشاء ملف جديد أضِف اسمه إلى `content/manifest.js`. وعند أي خطأ في الصيغة يظهر تنبيه في أداة المطوّر (Console) يحدد الملف والسطر.

### 1) وحدة دروس — `K.unitT`

```js
K.unitT(3,'اسم الوحدة','🔗',`
## عنوان الدرس الأول
سطر عادي يصبح فقرة شرح، و**النص بين نجمتين** يظهر عريضًا.
= سطر يبدأ بـ (= ) يصبح «مثالًا» في مربع ملوّن
> سطر يبدأ بـ (> ) يصبح «قاعدة» 💡
mc|السؤال؟|الإجابة الصحيحة|خطأ|خطأ|h=تلميح يظهر بعد الإجابة
tf|عبارة صح أو خطأ|1
in|سؤال إجابته مكتوبة|إجابة/إجابة أخرى مقبولة|s
or|رتّب الكلمات|كلمة كلمة كلمة|alt=ترتيب آخر صحيح
lt|رتّب الحروف|كلمة
## عنوان الدرس الثاني
...
`);
```

- **الإجابة الصحيحة تُكتب أولًا دائمًا**، والخيارات تُخلط عند العرض.
- `tf`: الرقم `1` = صح، و`0` = خطأ.
- `in`: الحرف `s` في الآخر يجعل التصحيح إملائيًّا صارمًا (يفرّق بين الهمزات والتاء والهاء).
- لزيادة وحدة: أنشئ `unit-9.js`، ثم غيّر الرقم في `LEVEL_UNITS` داخل `manifest.js`.

### 2) كلمات المعجم — `K.wordsT` (سطر لكل كلمة)

```
الكلمة|رمز|المعنى|جملة|مرادفات، مفصولة|أضداد|الجمع|ج ذ ر|من أسرتها|من الحياة
```

في مجموعة `fusha` يُضاف عمود أخير للفظ العامي. وفي مجموعة `quran` يُضاف عمودان: الآية، ثم موضعها.

### 3) أنواع أخرى

| النوع | الدالة | مثال مختصر |
|---|---|---|
| نص إملاء | `K.dictation([...])` | `{id:'g101',t:'النص',lvl:3,k:'short',rule:'hmid'}` |
| آية إملاء | `K.quran([...])` | `{id:'q2-1',s:2,sn:'البقرة',a:1,t:'نص الآية بالرسم الإملائي'}` |
| قصيدة | `K.poem({...})` | `body:[['الصدر','العجز']]` مع `gloss` و`q` و`src` |
| نص قراءة | `K.reading({...})` | `body:'فقرة\nفقرة'` مع `q:[تدريبات]` |
| مثل | `K.proverbs([...])` | `{p,m,use,story,src}` |
| لغز | `K.riddles([...])` | `{q,a,h,src:'تراثي'|'أصلي'}` |
| نص إلقاء | `K.speech([...])` | `{id,t,k:'نطق',lvl,body,tip}` |
| بنك لعبة | `K.gameBank('irab',[...])` | `{s,w,a,d}` |
| ملف صوت | `K.audio({...})` | `{"d:g001":"audio/d-g001.mp3"}` |

> **من داخل الموقع أيضًا:** ركن ولي الأمر ← «إضافة محتوى» يضيف 7 أنواع على الجهاز نفسه، ثم يصدّرها ملف `custom-content.js` جاهزًا لتضعه في `content/`.

## الصوت

- **الإملاء القرآني:** يُشغّل كل آية بصوت القارئ من موقع **EveryAyah** المجاني (الحصري المعلّم افتراضيًّا، ويمكن اختيار قارئ آخر من ركن ولي الأمر). يحتاج إلى الإنترنت.
- **ترتيب مصادر الصوت في كل مكان:** تسجيل ولي الأمر ← ملف في `audio/` ← صوت المتصفح العربي (إن وُجد) ← عرض النص لثوانٍ.
- **قائمة التسجيل:** في `docs/audio-scripts.md`: 100 نص إملاء، و30 نموذج إلقاء، و460 كلمة، لكل منها معرّف واسم ملف مقترح.
- لا تُستعمل أصوات أشخاص دون إذنهم، ولا أصوات تقلّد مشاهير.

## الأمانة العلمية وحقوق النشر

- **الشعر:** من شعراء قدامى، أو محدثين مضى على وفاتهم أكثر من 70 عامًا. وما لم تثبت نسبته كُتب فيه «يُنسب إلى…».
- **الحكايات:** مصنّفة: «موثّق» (قرآن أو حديث صحيح بمصدره)، أو «حكاية شعبية»، أو «رمزية»، أو «رواية أدبية»، أو «طرفة أصلية».
- **الأمثال:** من «مجمع الأمثال» للميداني، والحديثان المذكوران بمصدريهما.
- **بقية النصوص** (القراءة، والدروس، والإلقاء) من إعداد المملكة.
- **الخطوط:** Amiri وEl Messiri وTajawal من Google Fonts (رخصة مفتوحة). والشخصية «ضادون» رسم أصلي بـSVG.

## الخصوصية والحفظ

- لا حسابات، ولا إرسال بيانات. التقدم في `localStorage`، والتسجيلات في `IndexedDB` داخل المتصفح.
- مسح بيانات المتصفح يمسح التقدم؛ لذلك نزّل **نسخة احتياطية** من ركن ولي الأمر بانتظام.
- رمز ولي الأمر يُحفظ مُجزّأً (SHA-256)، وهو حماية من العبث، وليس تشفيرًا أمنيًّا.

## الاختبار

اختُبر المشروع آليًّا في متصفح Chrome على مقاسَي جوال (390px) وحاسوب (1280px):

- **122 صفحة:** بلا أخطاء، وبلا تمدد أفقي، وكل زر له نص أو وصف.
- **1194 رابطًا داخليًّا:** تعمل كلها.
- **3200 تدريب في المستويات** ومعها تدريبات كل الأقسام: أُجيب عن كل منها بمفتاحه ونجح.
- **19 لعبة:** جُرّبت كل لعبة في مستوياتها الثلاثة.
- **التسجيل الصوتي:** المسرح وركن ولي الأمر.
- **النسخ الاحتياطي:** التنزيل ثم الاستعادة في متصفح جديد فارغ.
