# نصوص التسجيل الصوتي — مملكة الضاد

هذه قائمة مرقمة بكل النصوص التي يمكن تسجيلها بصوت بشري (صوتك، أو معلم، أو قارئ تملك إذنه، أو أداة توليد صوت تملك حق استخدام صوتها).

**طريقتان لإضافة التسجيلات:**
1. من داخل الموقع: ركن ولي الأمر ← التسجيلات ← 🎙️ تسجيل أو ⬆️ رفع ملف (يُحفظ على الجهاز نفسه).
2. لكل الأجهزة: ضع الملفات في مجلد `audio/` باسم الملف المقترح، ثم سجّلها في `content/audio/manifest.js` هكذا:

```js
K.audio({
  "d:g001": "audio/d-g001.mp3",
  "s:s-umm": "audio/s-s-umm.mp3"
});
```

> آيات الإملاء القرآني تُشغَّل تلقائيًا بأصوات القرّاء من EveryAyah، ويمكن استبدالها بتسجيلك (المعرّف `q:...`).
